# Git

- Commit only when the owner asks, and only the files the owner names.
- Commit messages are in English, imperative, and name the task ID when there is
  one: `M1-08: add playback to the virtual microphone`.
- No attribution lines in commit messages or merge request text.
- Push only when the owner asks, to the branch the owner names.
- Never commit what `docs/folder-structure.md` lists under "Never in the repo".
