## Method

The signed `.app` was started with `open -n`, left alone with no meeting for 60 s, and then measured. The window opens on the Home screen (amended AC-1). AC-4 and AC-8 say "Setup screen"; this run was on Home, the screen the app opens on.

## Measurement (AC-8)

| Item | Value | Command |
|---|---|---|
| Resident memory, 64 s after launch | 70368 KB (about 68.7 MiB) | `ps -o etime=,rss= -p 87835` printed `01:04  70368` |
| Bundle size on disk | 5.7M | `du -sh Interlo.app` printed `5.7M` |

The release binary alone is 5897168 bytes (`docs/m0/M0b-02.md`).

One earlier run on an earlier build of the same code (binary sha256 `9c1c3c2c…c676`, pid 99397) printed `01:03  95312` for the same command. One reading per build is a single sample: the resident size of a webview app changes from run to run, so read these as a range of about 69 to 93 MiB, not as one exact figure. The reading above is the one for the bundle that was signed and verified for this pull request.

## Sockets (AC-4)

```text
$ ps -p 87835 -o pid=,etime=
87835 01:04
$ lsof -nP -a -p 87835 -i
$ echo $?
1
$ ps -p 87835 -o pid=,etime=
87835 01:04
```

The process was alive before and after `lsof`. `lsof` printed no line and exited 1, so the app process held no network socket: no non-loopback remote address and no wildcard listener.

Limits of the method:
- One reading at 64 s. A connection shorter than the reading is not seen.
- `-p <pid>` covers the app process only. The system web view runs in helper processes that this check does not list.
- The UI is loaded from the bundled files; no local dev server was running.

## The scripted version of these readings

The readings above came from single commands. `scripts/check.sh app` takes them again with raw logs, three launches, a spread, a socket sample every second over the app and its web view helper processes, and negative controls (`docs/testing.md`). Its run on the final commit has not been made: on 2026-11-23 it was BLOCKED because the Mac screen was locked (`CGSSessionScreenIsLocked` is true), and earlier runs of 2026-11-20 and 2026-11-23 ended early because the app process ended by itself (no crash report; cause not found). Until that run exists, the numbers in this note stay single readings.

## What this does not show

- A target. None is set yet; one is set after the number exists.
