# M0b-03: Bundle size, idle memory and sockets of the desktop shell

Recorded 2026-11-20 on the owner's machine. The shell is the React shell only (D-191): the window, the sidebar and the screens with sample or empty data. No audio, no engine, no model is loaded, so these numbers are a floor for the app, not an estimate of it.

## Setup

| Item | Value |
|---|---|
| macOS | 26.4.1 (build 25E253) |
| Mac model | Mac mini, Mac16,11, Apple M4 Pro, 24 GB |
| rustc | 1.99.1 (58cf8f9c3 2026-10-13) |
| Commit | `9f8c1e7` (the bundle was built from the code of `cd43c97`; `9f8c1e7` only adds a note) |
| Bundle method | `cargo tauri build --bundles app --config '{"bundle":{"active":true}}'` (one-off override; `tauri.conf.json` is unchanged) |
| Signature | `codesign --force --deep --sign "Interlo Local Signing"`; `codesign --verify --deep --strict` exits 0 (AC-7) |
| Binary sha256 | `9c1c3c2c454462c167895ecb117ce94f2d75e61dc808bc48c4a5bc55945bc676` |

## Method

The signed `.app` was started with `open -n`, left alone with no meeting for 60 s, and then measured. The window opens on the Home screen (amended AC-1); nobody touched it during the 60 s.

## Measurement (AC-8)

| Item | Value | Command |
|---|---|---|
| Resident memory, 63 s after launch | 95312 KB (about 93 MiB) | `ps -o etime=,rss= -p 99397` printed `01:03  95312` |
| Bundle size on disk | 5.7M | `du -sh Interlo.app` printed `5.7M` |

The release binary alone is 5897168 bytes (`docs/m0/M0b-02.md`).

## Sockets (AC-4)

```text
$ lsof -nP -a -p 99397 -i
$ echo $?
1
```

`lsof` printed no line and exited 1, which means the process held no network socket at all: no non-loopback remote address and no wildcard listener.

Limit of the method: one reading at 63 s. A connection shorter than the reading is not seen. The Tauri shell loads the UI from the bundled files, so no local dev server is involved in this run.

## What this does not show

- Memory with a live meeting, a model or an audio route: those come with M0b-05 and later tasks.
- A target. None is set yet; one is set after the number exists.
