## Notes

- The gate runs in two places: locally before a change goes up, and in GitHub CI (`check (macos-15)`) on every pull request and every push to `main`.
- The local seconds are short because this run reused the Rust build of an earlier attempt in the same checkout (see the next note). A clean build takes longer; the CI column shows a build from the runner cache.
- An earlier attempt in the fresh checkout exited 2: `ui lint` reported `NOT CONFIGURED` because `apps/ui/node_modules` was missing. The gate did not count it as a pass. After `npm --prefix apps/ui ci --ignore-scripts` (the install step CI uses) the run above exited 0.
- The dependency audit is a separate mode, `scripts/check.sh supply`, and is not part of this evidence.
