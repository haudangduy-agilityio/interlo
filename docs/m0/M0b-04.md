4. Press Cmd+A, Cmd+C, and copy nothing else afterwards.
5. Run, with a UTF-8 locale:

```bash
export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8

printf '%s' "Hôm nay mình rảnh, cũng gặp nhau ở quán bạn nhé." > sentence.txt

```
