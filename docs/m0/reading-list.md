# Reading list for the M0 and M1 measurements

This file holds every sentence, term and clip text that the speech measurements read aloud or score.
Read by: M0-03, M0-04, M0-05, M0-06, M0-13, M1-23, M1-26.
No audio is saved. The list is text only (D-51).
The Vietnamese text is test data. It is the only Vietnamese text in the documents, by owner decision of 2026-11-20.
Accent groups: us, in, vn.
The groups are US English, Indian English and Vietnamese-accented English. All three groups read the same ten English sentences.
Run ID: en_<group>_<nnn>, for example en_us_001; derived, not stored as a row.
Term policy: keep in English.
A clip is `plain` when it holds no term of the other language and `cross` when it holds exactly one.
The sentences come from the Recording Kit page. One wording change: `en_002` names no browser or phone brand.
