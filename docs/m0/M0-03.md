# M0-03: bench harness

Task M0-03 of FT-03. Code: `bench/M0-03/` (own `[workspace]`, D-190, no dependency, never imported by
product code). Run it with `bench/M0-03/target/release/m0-03 run --stage energy_ref --file <wav>
--log <path>`; the full instructions, the log format (version 1) and how to add a stage are in
`bench/M0-03/README.md`.

The harness runs one stage on one WAV file and writes a text log in which every line is stamped from
one session clock. Replaying the same file gives the same event order; the comparison command is in
the README. It carries one reference stage, `energy_ref`, that needs no model and is not the
product's voice activity detector.

This task measures nothing, so this note holds no numbers. M0-04, M0-05 and M0-09 add their own
stages and write their numbers in their own notes.
